# 序事 · 任务管理器

基于 Vue 3、Vite 和 Tailwind CSS 的任务管理器 MVP。无需后端，任务和主题设置保存在当前浏览器的 `localStorage` 中。

## 启动

需要 Node.js 20.19+。

```bash
npm install
npm run dev
```

打开终端显示的本地地址。生产构建使用 `npm run build`，预览构建结果使用 `npm run preview`。

## 功能

- 创建、查看、编辑和删除任务；标题必填，描述选填。
- 待办、进行中、已完成三列看板。在桌面浏览器中拖动卡片即可改变状态；也可在编辑表单中修改状态。
- 高（红）、中（黄）、低（绿）三档优先级，支持搜索和按优先级筛选。
- 一键切换深色模式，任务及主题设置在刷新后保留。
- 展示任务总数、进行中数量、已完成数量和完成进度。

数据只保存在当前浏览器和当前站点，不会在不同设备之间同步。清除该站点的浏览器数据会删除任务。
